# Cyber-security-project

To run the application, install Python 3 and download the project files and make sure that the app.py file and the templates folder are in the same project directory.

When the files are downloaded, open terminal and follow the following rules depending on your OS: 
On Windows, run python app.py in the project folder.
On Linux and macOS, run python3 app.py.

The app creates its own SQLite database automatically when it starts.
Open http://127.0.0.1:8000/login in a browser.

When trying the fixes, check from each flaw paragraph which lines you should remove comments from and which ones to comment out. Before making any changes to the code you should always stop the server on the terminal by pressing Ctrl + C and after the changes are done, save app.py and start the server again.
